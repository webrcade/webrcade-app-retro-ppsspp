# webЯcade Application: Sony PSP Emulator

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

The Sony PSP application for [webЯcade](https://www.webrcade.com) is an emulator for the [Sony PlayStation Portable game console](https://en.wikipedia.org/wiki/PlayStation_Portable).

The underlying emulator is [PPSSPP](https://github.com/hrydgard/ppsspp).

## Documentation

The [Sony PSP Application Documentation](https://docs.webrcade.com/apps/emulators/psp/) includes [keyboard](https://docs.webrcade.com/apps/emulators/psp/#keyboard) and [gamepad](https://docs.webrcade.com/apps/emulators/psp/#gamepad) control mappings, information related to [saves](https://docs.webrcade.com/apps/emulators/psp/#saves) support, and details regarding the use of the emulator within a [webЯcade feed](https://docs.webrcade.com/apps/emulators/psp/#feed).
